Books API

A simple REST API built with Express to manage a list of books.

Welcome

The books are stored in memory, so when the server restarts the list goes back to its original state.

Endpoints

Method Path Description
GET /books Returns the full list of books
POST /books Adds a new book (title and author in the body)
GET /books/:id Returns a single book by its id
DELETE /books/:id Deletes a book by its id

Example

Body of a POST /books request (JSON):

{ "title": "1984", "author": "George Orwell" }
